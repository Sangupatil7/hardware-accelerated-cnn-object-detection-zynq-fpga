# Hardware-Accelerated CNN-Based Object Detection Using Xilinx Zynq FPGA

## Project Overview
This project implements a real-time object detection system using a hardware-accelerated Convolutional Neural Network (CNN) on a Xilinx Zynq FPGA platform. The architecture integrates FPGA-based programmable logic (PL) with the ARM processing system (PS) to accelerate computationally intensive CNN operations.

## Key Features
- CNN-based object detection.
- Hardware acceleration using Xilinx Zynq FPGA.
- ARM processor and FPGA programmable logic integration.
- AXI-based communication interfaces.
- Low-latency processing architecture.
- Hardware-software co-design.

## Technologies & Tools
- **Hardware:** Xilinx Zynq FPGA
- **Development Tools:** Vivado, Vitis
- **Programming:** C/C++
- **Architecture:** CNN, ARM Processing System, Programmable Logic
- **Interfaces:** AXI

## System Architecture
The system uses the ARM processor for application-level processing and FPGA programmable logic to accelerate computationally intensive CNN operations. Communication between the processing system and programmable logic is established through AXI interfaces.

## Implementation
1. Developed the CNN-based object detection architecture.
2. Integrated hardware acceleration using FPGA programmable logic.
3. Connected the ARM processing system and FPGA through AXI interfaces.
4. Configured and validated the hardware design using Vivado and Vitis.
5. Evaluated the system for low-latency object detection.
